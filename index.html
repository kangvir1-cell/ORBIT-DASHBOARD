Workflow Guide

01 — Set Site CodeEnter the Amazon station/site code at the top, e.g. JULD.
02 — Set VR IDEnter the Vehicle Run ID before scanning any orphan.
03 — Scan OrphanScan the physical barcode or enter the ASIN. ORBIT attempts automatic product identification.
04 — Verify DetailsCheck Product, Image, ASIN and VALUE (INR) in the preview.
05 — ProcessRecord remains Pending until a TID is entered. Adding a TID marks it Completed.
06 — TraceabilityEvery record stays linked to Site Code + VR ID for receiving traceability.
